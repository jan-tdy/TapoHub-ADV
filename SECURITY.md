# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately using [GitHub Security Advisories](https://github.com/jan-tdy/tapo_hub/security/advisories/new)
rather than opening a public issue.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it, if possible.
- Any relevant logs (with credentials and personal data redacted).

You should receive an initial response within a reasonable time. Fixes are
released as soon as practical given this is a small, unfunded open-source
project maintained on a best-effort basis (see the Disclaimer in
[README.md](README.md)).

## Scope

This policy covers the code in this repository. It does **not** cover:

- The upstream [python-kasa](https://github.com/python-kasa/python-kasa) library
  or the third-party [`feature/tpap` fork](https://github.com/ZeliardM/python-kasa)
  this integration depends on — report issues with those directly to their
  maintainers.
- Home Assistant core itself.
- TP-Link/Tapo firmware or cloud services.
